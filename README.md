# オセロ評価AI

スマホのカメラでオセロ盤を撮影するだけで、将棋の指し手評価AIのように
「勝率(数値)」と「その理由の解説文」を表示するアプリです。

**外部APIキーは不要です。** 盤面の読み取り・勝率計算・解説文生成のすべてが
アプリ内で完結します(下記「なぜLLMを使わないか」参照)。

## アーキテクチャ / なぜこの構成か

将棋・囲碁・オセロのような完全情報ゲームでは、勝率の計算自体をLLMに
任せると根拠が曖昧で数値も不安定になります。そこで本アプリでは役割を
分けています。

| 役割 | 担当 | 実装 |
| --- | --- | --- |
| 写真 → 8×8盤面の読み取り | 古典的な画像処理(ブラウザのCanvas API) | `lib/boardVision.ts` |
| 勝率・最善手の計算 | 自作のαβ探索エンジン | `lib/othello.ts` |
| 解説文の生成 | ルールベースの日本語テンプレート | `lib/explain.ts` |

盤面が終盤(空きマス10以下、`lib/othello.ts`の`EXACT_EMPTY_THRESHOLD`で調整可)になると、探索エンジンは
ゲーム終了まで完全読み切りを試みます。それより手前では位置評価(角・
着手可能数・確定石の少なさなど)を使ったヒューリスティック探索になります。

### なぜLLMを使わないか

当初はGemma/Gemini(マルチモーダルLLM)で盤面読み取りと解説文生成を
行っていましたが、実運用で以下のようなトラブルが連続しました。

- モデルの世代交代・廃止によるAPIの404(Gemma 3→4、`gemini-2.0-flash`廃止など)
- 応答が遅いモデルをタイムアウトさせてしまう問題
- `503 UNAVAILABLE`(高負荷)がモデルファミリー全体に同時発生し、
  3段のフォールバックを組んでも解消しないケース

一方で、撮影ガイド(黄色い正方形の枠)によって「盤面が正方形いっぱいに
写る」ことがほぼ保証されるようになったため、盤面読み取りは以下のような
古典的な画像処理で十分実用的に行えると判断し、完全移行しました。

1. 明るさ(輝度)の行・列ごとの合計から、盤面の格子線(9本×9本)の位置を推定
   (理想的な等間隔位置を基準に、実際に最も暗い行/列へスナップさせることで、
   撮影ガイドに完全に一致しなくてもある程度のズレを許容)
2. 各マスの中央付近の平均輝度を計算し、写真全体の中での相対的な明暗
   (このマスは他と比べて暗いか/明るいか)から黒石・白石・空きを判定

解説文もLLMではなく、探索エンジンが出した数値(勝率・角の差・着手可能数の差
など)をそのまま日本語テンプレートに埋め込んで生成しています。数値の
正確さ・再現性・速度(ネットワーク呼び出しなし)を優先した設計です。

古典的な画像処理は照明のムラや極端な角度に弱いため、読み取り後に
タップして黒→白→空きを修正できるUIを必ず経由します。撮影せずに
最初から手入力することも可能です。

## 使い方

1. 「初期配置から開始」を押す(または「今の盤面を撮影して開始」で対局途中から)
2. 実際の盤に石を置いたら、「石を置いたら撮影」ボタンでその瞬間の盤面を撮影
   (将棋の対局時計のボタンのような感覚で、1手ごとに押す)
3. 盤面が自動で読み取られるので、間違っていればタップして修正し、次の手番を確認
4. 「この盤面で評価する」を押すと、勝率バーと解説文が表示される
5. 次の一手が打たれたら 2〜4 を繰り返す

## セットアップ

```bash
npm install
npm run dev
```

環境変数の設定は不要です。`npm run test` でエンジンと画像処理アルゴリズムの
自己テストを実行できます(`npm run test:engine` / `npm run test:vision` で
個別実行も可能)。

## Vercelへのデプロイ

1. このリポジトリをGitHubに接続してVercelでインポート
2. 環境変数の設定不要でそのまま Deploy

`/api/evaluate` は探索エンジンの計算のみを行うため、`maxDuration = 15`
で十分な余裕があります。

## 開発メモ

- `lib/othello.ts`: ルール実装・αβ探索・勝率変換。`npm run test:engine`
  で動作確認できます。
- `lib/boardVision.ts`: 写真から盤面を読み取る画像処理アルゴリズム。DOM
  に依存しない純粋関数なので、`npm run test:vision`(`scripts/test-vision.ts`
  内で合成画像を生成してテスト)でNode上から検証できます。
- `lib/imageCapture.ts`: File/`<video>`からCanvas経由でImageDataを取り出す
  ブラウザ専用ヘルパー(`lib/boardVision.ts`本体はここに依存しません)。
- `lib/explain.ts`: 探索結果を日本語の解説文に変換するテンプレート生成。
- 評価値→勝率の変換式やヒューリスティックの重みは簡易的なチューニングです。
  実戦で精度が気になる場合は `lib/othello.ts` の `evaluateHeuristic` や
  探索深さ (`pickHeuristicDepth`) を調整してください。
- 盤面読み取りの精度が気になる場合は `lib/boardVision.ts` の
  `LOW_CONTRAST_CUTOFF` や閾値の重み(0.33 / 0.66)、`lib/imageCapture.ts`
  の `ANALYSIS_SIZE` を調整してください。
